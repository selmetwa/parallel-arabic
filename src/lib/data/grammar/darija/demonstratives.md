Darija has a handy short form, **had**, which means "this" or "these" and goes before a noun with **l-** ("the").

## had + l-: the everyday "this"

**had** never changes for gender or number:

```ex
هاد الكتاب زوين | had l-ktab zwin | This book is nice.
هاد البنت ختي | had l-bent khti | This girl is my sister.
هاد الناس | had n-nas | these people
```

## "This is…"

Use the full forms, with the noun after them and no **l-**:

| | This | That |
| --- | --- | --- |
| masculine | هادا hada | داك dak |
| feminine | هادي hadi | ديك dik |
| plural | هادو hadu | دوك duk |

```ex
هادا كتابي | hada ktabi | This is my book.
هادي طوموبيل جديدة | hadi tomobil jdida | This is a new car.
```

## "That"

**dak**, **dik** and **duk** work like **had**, before a noun with **l-**:

```ex
داك الراجل | dak r-rajel | that man
ديك الدار | dik d-dar | that house
```

> Notice that **dar** (house) is feminine in Darija, so it's **dik d-dar**, not *dak d-dar*.
