Darija uses **ila** for real conditions ("if it rains") and **kun** for imagined ones ("if I were rich").

## Real conditions: ila + past

After **ila**, use the **past** tense, even when you're talking about the future. The result usually uses **ghadi** or a command.

```ex
إلا جات، غادي نقولها | ila jat, ghadi nqulha | If she comes, I'll tell her.
إلا عندك الوقت، أجي | ila 3ndek l-weqt, aji | If you have time, come over.
إلا ما جاش، عيط ليا | ila ma jash, 3eyyet liya | If he doesn't come, call me.
```

## Imagined conditions: kun … kun

For something unreal, or something that didn't happen, put **kun** at the start of both halves:

```ex
كون كنت عرفت، كون قلتها ليك | kun kont 3reft, kun qoltha lik | If I had known, I would have told you.
كون كان عندي الفلوس، كون شريتها | kun kan 3ndi l-flus, kun shritha | If I'd had the money, I would have bought it.
```

## Useful combinations

```ex
واخا | wakha | even if; OK
إلا ما | ila ma | unless, if not
إلا بغيتي | ila bghiti | please (literally "if you want")
```
