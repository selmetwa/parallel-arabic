Some verbs follow the conjugation patterns exactly. Others change shape because their root has a **weak letter**: **w**, **y** or a hamza (**ء**). The verb's class tells you which kind it is.

## Sound verbs

Three ordinary consonants, no surprises.

```ex
كتب / كتبت / كيكتب | kteb / ktebt / kayekteb | he wrote / I wrote / he writes
```

## Hollow verbs: w or y in the middle

The middle letter shows up as a long vowel, which **shortens** or disappears before endings that start with a consonant.

| | Past (he) | Past (I) | Present (he) |
| --- | --- | --- | --- |
| see | شاف shaf | شفت shft | كيشوف kayshuf |
| say | قال qal | قلت qolt | كيقول kayqul |
| sell | باع ba3 | بعت b3t | كيبيع kaybi3 |

## Defective verbs: w or y at the end

The verb ends in a vowel, which merges with the endings:

| | Past (he) | Past (I) | Present (he) |
| --- | --- | --- | --- |
| forget | نسا nsa | نسيت nsit | كينسى kaynsa |
| walk, go | مشا msha | مشيت mshit | كيمشي kaymshi |
| buy | شرا shra | شريت shrit | كيشري kayshri |

## Doubled verbs: the same letter twice

The second and third root letters are the same. Before consonant endings, they add **-i-**:

```ex
حل / حليت / كيحل | 7ell / 7llit / kay7ell | he opened / I opened / he opens
```

## Irregular verbs

A few very common verbs don't fit any pattern:

```ex
جا / جيت / كيجي | ja / jit / kayji | he came / I came / he comes
كلا / كليت / كياكل | kla / klit / kayakul | he ate / I ate / he eats
خدا / خديت / كياخد | khda / khdit / kayakhud | he took / I took / he takes
```

> Each verb in the [verb tables](/darija/conjugations) is labelled with its class.
