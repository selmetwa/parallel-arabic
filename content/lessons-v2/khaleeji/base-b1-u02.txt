# Khaleeji — B1 — The Conditional (base-b1-u02)
# إذا = real condition; لو + كان (chaan) = hypothetical; اللي = who / which / that.
# Gulf: مِتى ما = whenever, عَيل = so / then, لولا = if not for, شو ما = whatever.
